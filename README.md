#Supplier Working Capital Intelligence System
Understand how supplier credit is tied up in inventory and use that information to make better cash-allocation decisions.

Problem: Small retail businesses often manage supplier credit using intuition and fragmented records. Owners know how much they owe each supplier, but may not know how much of that supplier's inventory is still sitting in their store at a given point in time.

Objective: Build a daily decision-support system that connects supplier payables with supplier-attributed inventory and cash position to improve payment timing and working-capital allocation.
